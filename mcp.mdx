Conecte a documentação e endpoints da API NextPay Gateway a ferramentas de IA através do nosso servidor MCP (Model Context Protocol) hospedado.

## O que é MCP?

O Model Context Protocol (MCP) é um protocolo aberto que cria conexões padronizadas entre aplicações de IA e serviços externos, como documentação. A Mintlify gera automaticamente um servidor MCP da sua documentação, preparando seu conteúdo para o ecossistema de IA onde qualquer cliente MCP (como Claude, Cursor, Goose e outros) pode se conectar à sua documentação.

## Como funciona

Quando uma ferramenta de IA como Claude, Cursor ou ChatGPT tem o servidor MCP da sua documentação conectado, a ferramenta pode pesquisar sua documentação diretamente durante a geração de respostas, em vez de fazer uma busca genérica na web.

- O LLM pode pesquisar proativamente sua documentação enquanto gera uma resposta, não apenas quando explicitamente solicitado
- O LLM determina quando usar a ferramenta de busca com base no contexto da conversa e na relevância da sua documentação
- Cada chamada de ferramenta acontece durante o processo de geração, permitindo que o LLM incorpore informações em tempo real da sua documentação na resposta

**Exemplo**: Se um usuário faz uma pergunta sobre integração e o LLM determina que a documentação da NextPay é relevante, ele pode pesquisar a documentação e incluir essas informações na resposta sem que o usuário peça explicitamente.

## Acesse o servidor MCP

O servidor MCP da NextPay Gateway está disponível publicamente em:

```
https://docs.nextpagamentos.io/mcp
```

<Info>
  Servidores MCP hospedados usam o caminho `/mcp` em suas URLs. Este caminho é reservado e não pode ser usado para outros elementos de navegação.
</Info>

## Como usar o servidor MCP

Para usar o servidor MCP da NextPay Gateway em suas ferramentas de IA favoritas, siga as instruções abaixo:

<Tabs>
  <Tab title="Claude">
    ### Conectar ao Claude

    1. Acesse a página [Connectors](https://claude.ai/settings/connectors) nas configurações do Claude
    2. Selecione **Add custom connector**
    3. Adicione o servidor MCP da NextPay:
       - **Name**: `NextPay Gateway`
       - **URL**: `https://docs.nextpagamentos.io/mcp`
    4. Selecione **Add**

    ### Usar no chat

    1. Ao usar o Claude, selecione o botão de anexos (ícone de mais)
    2. Selecione o servidor MCP da NextPay Gateway
    3. Faça perguntas sobre a API NextPay Gateway

    <Tip>
      Veja a [documentação do Model Context Protocol](https://modelcontextprotocol.io/docs/tutorials/use-remote-mcp-server#connecting-to-a-remote-mcp-server) para mais detalhes.
    </Tip>
  </Tab>

  <Tab title="Claude Code">
    ### Instalar via linha de comando

    Execute o seguinte comando para adicionar o servidor MCP da NextPay:

    ```bash
    claude mcp add --transport http NextPayGateway https://docs.nextpagamentos.io/mcp
    ```

    ### Testar a conexão

    ```bash
    claude mcp list
    ```

    <Tip>
      Veja a [documentação do Claude Code](https://docs.anthropic.com/en/docs/claude-code/mcp#installing-mcp-servers) para mais detalhes.
    </Tip>
  </Tab>

  <Tab title="Cursor">
    ### Configuração manual

    1. Use **Command + Shift + P** (Ctrl + Shift + P no Windows) para abrir a paleta de comandos
    2. Pesquise por "Open MCP settings"
    3. Selecione **Add custom MCP**. Isso abre o arquivo `mcp.json`
    4. Em `mcp.json`, adicione:

    ```json
    {
      "mcpServers": {
        "NextPayGateway": {
          "url": "https://docs.nextpagamentos.io/mcp"
        }
      }
    }
    ```

    ### Testar a conexão

    No chat do Cursor, pergunte "What tools do you have available?" O Cursor deve mostrar o servidor MCP da NextPay Gateway como uma ferramenta disponível.

    <Tip>
      Veja a [documentação do Cursor](https://docs.cursor.com/en/context/mcp#installing-mcp-servers) para mais detalhes.
    </Tip>
  </Tab>

  <Tab title="VS Code">
    ### Configuração manual

    1. Crie um arquivo `.vscode/mcp.json`
    2. Em `mcp.json`, adicione:

    ```json
    {
      "servers": {
        "NextPayGateway": {
          "type": "http",
          "url": "https://docs.nextpagamentos.io/mcp"
        }
      }
    }
    ```

    <Tip>
      Veja a [documentação do VS Code](https://code.visualstudio.com/docs/copilot/chat/mcp-servers) para mais detalhes.
    </Tip>
  </Tab>
</Tabs>

## Ferramentas disponíveis

O servidor MCP da NextPay Gateway expõe uma ferramenta de busca que permite:

- **Pesquisar documentação**: Buscar informações relevantes em toda a documentação da API
- **Encontrar exemplos de código**: Localizar exemplos de implementação específicos
- **Consultar referências da API**: Acessar detalhes sobre endpoints, parâmetros e respostas
- **Entender recursos**: Obter explicações sobre como funcionalidades específicas funcionam

## Casos de uso

- **Desenvolvimento**: Desenvolvedores podem fazer perguntas sobre integração diretamente no IDE
- **Suporte**: Equipes de suporte podem obter respostas rápidas e precisas sobre a API
- **Aprendizado**: Novos usuários podem aprender sobre a API de forma interativa
- **Debugging**: Encontrar soluções para problemas específicos com contexto da documentação oficial

<Warning>
  O servidor MCP está disponível apenas para documentação pública. Documentação protegida por autenticação não pode gerar um servidor MCP.
</Warning>
