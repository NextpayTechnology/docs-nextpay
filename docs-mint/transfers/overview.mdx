# Transferências - Visão Geral

As transferências permitem que você solicite saques (cashout) do seu saldo disponível para uma chave PIX.

## O que são Transferências?

Uma transferência é uma solicitação de saque do saldo disponível na sua conta para uma chave PIX. O processo é:

1. Você solicita uma transferência informando o valor e a chave PIX
2. O sistema valida o saldo disponível e as configurações
3. A transferência é processada e o valor é enviado para a chave PIX informada

## Requisitos

- Saldo disponível suficiente
- Chave PIX válida
- Configuração de transferências habilitada na sua conta
- Permissão para realizar saques via API (se aplicável)

## Limites

- **Valor mínimo**: R$ 1,00
- **Valor máximo**: R$ 100.000,00 por transferência
- **Taxas**: Podem ser aplicadas taxas fixas e/ou percentuais conforme configuração

## Status de Transferência

As transferências podem ter os seguintes status:

| Status | Descrição |
|--------|-----------|
| `PENDING` | Aguardando processamento |
| `PROCESSING` | Em processamento |
| `COMPLETED` | Transferência concluída |
| `FAILED` | Falha no processamento |
| `CANCELLED` | Transferência cancelada |

## Tipos de Chave PIX

A API suporta os seguintes tipos de chave PIX:

- `CPF` - CPF (padrão)
- `CNPJ` - CNPJ
- `EMAIL` - Email
- `PHONE` - Telefone
- `RANDOM` - Chave aleatória
